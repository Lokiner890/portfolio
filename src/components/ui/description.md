# ui

UI components, also known as reusable components, are the basic building blocks of the interface. They allow developers to write a piece of code once and use it in multiple places across the application, enhancing the DRY (Don't Repeat Yourself) principle.

A UI component is a self-contained unit of code that encapsulates its own logic and view, without business logic or API calls. It can accept parameters (props), allowing it to have different configurations depending on where it is used.

example button, input, radio, checkbox, loader, etc.
